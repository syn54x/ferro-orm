*[ADR]: Architecture Decision Record: a short note that records one design decision and why it was made
*[ASGI]: Asynchronous Server Gateway Interface: the async Python web server standard
*[CRUD]: Create, Read, Update, Delete
*[DBAPI]: Python Database API (PEP 249)
*[DDL]: Data Definition Language: the CREATE, ALTER and DROP statements that change a schema
*[DML]: Data Manipulation Language: the INSERT, UPDATE and DELETE statements that change rows
*[FFI]: Foreign Function Interface: the boundary between Ferro's Python layer and its Rust core
*[FK]: Foreign key
*[FKs]: Foreign keys
*[GIL]: Global Interpreter Lock
*[GUC]: Grand Unified Configuration: a key/value Postgres runtime setting, such as the ones a Session applies for Row-Level Security
*[GUCs]: Grand Unified Configuration settings: key/value Postgres runtime settings, such as the ones a Session applies for Row-Level Security
*[IR]: Intermediate representation: the description of models or a query that Ferro's Python layer hands to its Rust core
*[JSONB]: Postgres binary JSON type
*[ORM]: Object-Relational Mapper
*[PK]: Primary key
*[RLS]: Row-Level Security: Postgres policies that decide which rows each connection may see or change
*[TTY]: Terminal
*[UUID]: Universally Unique Identifier
